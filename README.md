# MyChaosPet

A browser-first virtual pet prototype for CrazyGames-style play sessions.

## Prototype

**My Chaos Pet** is an original virtual pet / arcade-care prototype. It is inspired by the general virtual pet genre, not by any specific character IP.

Core loop:

- Care for Mochi
- Feed, clean, nap, and play
- Earn coins and XP
- Unlock cosmetics and rooms
- Complete daily quests and achievements
- Play short 20-second minigames

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Notes

This is a prototype. The rewarded bonus button is simulated only and does not show real ads. For a CrazyGames release build, connect the CrazyGames SDK, save API, consent flow, audio, mobile input polish, and production bundling.
